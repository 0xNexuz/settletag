SHEET 04 / TESTNET FUNDING

Get test MUSD■

For a small payment test, connect a browser wallet and get test BTC from Mezo’s faucet and swap a little for MUSD. The faucet does not dispense MUSD.

01

Copy wallet address

Create or unlock a test wallet first.

02

Request test BTC

Paste the address into the official faucet and complete its CAPTCHA. Keep some test BTC for transaction fees.

Open official faucet ↗
03

Swap a small amount

Connect a browser wallet to Mezo testnet. In the Mezo app, open Swap and choose BTC → MUSD. Review the live quote, fees, and slippage before confirming. No 1,800 MUSD loan is needed for a swap.

Open Mezo testnet ↗Read Mezo Swap guide ↗
04

Borrow instead

Borrowing mints MUSD against BTC collateral, but the minimum loan is 1,800 MUSD. Use this path only if you want a loan position.

Open MUSD borrow ↗

The easiest route is to use one browser wallet for the faucet, Mezo Swap, and SettleTag. If you created a wallet inside SettleTag, you can send test BTC to your extension wallet from the Wallet sheet, swap there, then send MUSD back to the SettleTag wallet address. Keep your recovery phrase private.
